# Portfolio listing

Title: Monthly Sales Review | Tableau

Role: Sales analysis, SQL preparation and Tableau report design

Description: Sales fell even as more orders came in. I compared December 1–30, 2018 with the same dates in 2017 using Python and SQL across 9,800 historical lines. Sales fell 12.6%, orders rose 33.5%, and sales per order fell 34.6%. The Tableau brief shows the category and regional changes worth investigating; they don't establish a cause. Includes the downloadable workbook, source records, and refresh guide, with Power BI and Excel companion reports. Independent project; source currency is unspecified.

Skills: Python; SQL; Microsoft Excel; Tableau; Data Analysis.

Repository: https://github.com/ZakJRademacher/monthly-sales-automation
